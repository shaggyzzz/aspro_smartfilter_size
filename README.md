# Фильтр «Размер» → попап «Ширина × Длина»

Надстройка над умным фильтром Битрикс (шаблон Аспро Макс).
Длинный список чекбоксов «ШxД» (80x190, 160x200, …) превращается в поле
**«Выберите размер»**, открывающее попап с двумя колонками — «Ширина, см» и
«Длина, см», как на mnogosna.ru:

- **десктоп** — выпадающая панель у поля;
- **мобильные (≤767px)** — шторка снизу на весь экран, с подложкой и
  блокировкой прокрутки страницы.

Серверная часть не меняется: исходные чекбоксы остаются в DOM (скрываются
стилями) и служат источником данных. Клик по кнопке размера вызывает
нативный `click()` соответствующего чекбокса — срабатывает штатный
`smartFilter.click()`, ajax и перерисовка каталога.

## Файлы

| Файл | Куда на сервере | Это обновление |
|---|---|---|
| `size-filter.js` | `/bitrix/templates/aspro_max/assets/size-filter/size-filter.js` | **заменить** — популярные размеры в попапе + пикер SKU на детальной |
| `size-filter.css` | `/bitrix/templates/aspro_max/assets/size-filter/size-filter.css` | **заменить** — стили популярных размеров и SKU |
| `result_modifier.php` | `/bitrix/templates/aspro_max/components/bitrix/catalog.smart.filter/main_ajax/result_modifier.php` | **залить / вставить блок** `$arOfferSizeItems` — «Размер» ТП выше фильтров товара |
| `demo.html` | не нужен на сайте | только локальная проверка |

`header.php` уже подключает js/css — его не трогать, только увеличить `?v=` у обоих файлов после замены.

## Что залить на сервер

1. Заменить `size-filter.js` и `size-filter.css` в
   `/bitrix/templates/aspro_max/assets/size-filter/`.
2. В `header.php` сменить, например, `?v=1` → `?v=2` у css и js (иначе браузеры
   отдадут старый кеш).
3. Обновить `result_modifier.php` умного фильтра:
   `/bitrix/templates/aspro_max/components/bitrix/catalog.smart.filter/main_ajax/result_modifier.php`
   (если файл уже кастомный — перенести только блок с `$arOfferSizeItems`).
4. Сбросить кеш Битрикса: Настройки → Настройки продукта → Автокеширование →
   «Очистить», плюс композитный кеш, если включён.

Проверить: каталог (фильтр «Размер» сверху, попап с популярными) и карточка
товара (тот же попап вместо селекта SKU).

## Установка на сайт (с нуля)

1. Загрузить файлы на сервер, например в
   `/bitrix/templates/aspro_max/assets/size-filter/`
   (шаблон сайта — `/bitrix/templates/aspro_max/`).

2. Подключить их в шаблоне — прямыми тегами в `<head>` файла
   `/bitrix/templates/aspro_max/header.php`, после блока с
   `window.SizeFilterConfig` (если он есть):

   ```php
   <link rel="stylesheet" href="<?=SITE_TEMPLATE_PATH?>/assets/size-filter/size-filter.css?v=1">
   <script src="<?=SITE_TEMPLATE_PATH?>/assets/size-filter/size-filter.js?v=1"></script>
   ```

   Скрипт нарочно без `defer`: анти-мерцательный стиль должен примениться
   до первой отрисовки. При обновлении файлов увеличивайте `?v=`, чтобы
   сбросить кеш браузеров.

   Вариант через `Asset::getInstance()->addCss()/addJs()` тоже возможен,
   но имейте в виду: **Битрикс молча пропускает несуществующие файлы** —
   при опечатке в пути тег просто не появится, без ошибок. Проверить путь
   можно, открыв файл по прямой ссылке:
   `https://<сайт>/bitrix/templates/aspro_max/assets/size-filter/size-filter.js`.

3. После правки header.php сбросить кеш: Настройки → Настройки продукта →
   Автокеширование → «Очистить», и композитный кеш, если включён —
   Аспро кеширует шапку, без сброса изменения могут не появиться.

4. Чтобы блок «Размер» (свойство ТП `razmer`) стоял выше фильтров товара,
   подставить `result_modifier.php` в шаблон умного фильтра Аспро:
   `/bitrix/templates/aspro_max/components/bitrix/catalog.smart.filter/main_ajax/result_modifier.php`
   (если файл уже кастомизирован — перенести только блок с `$arOfferSizeItems`).
   После замены сбросить кеш компонента фильтра. Итоговый порядок:
   Сортировка → Размер → цена → свойства товара.

5. Готово. Скрипт сам находит блоки фильтра с `data-prop_code="razmer"`
   на всех страницах каталога (и в мобильной панели фильтра тоже) и
   переинициализируется после каждой ajax-перерисовки фильтра.
   На детальной странице товара тот же попап ставится над селектом SKU
   (`.bx_item_detail_size`): выбирается одно ТП, срабатывает штатный
   `change` Аспро (цена, артикул, `oid`). Отключить: `skuEnabled: false`.

## Настройки

Задать `window.SizeFilterConfig` **до** подключения `size-filter.js`
(любой параметр можно опустить — останется значение по умолчанию):

```html
<script>
window.SizeFilterConfig = {
  propCodes: ['razmer'],            // символьные коды свойств-«размеров»
  popupTitle: 'Выберите размер (Ш × Д)',
  placeholder: 'Выберите размер',   // текст поля, пока ничего не выбрано
  selectedText: 'Выбрано размеров', // текст поля при выборе 2+ размеров
  widthTitle: 'Ширина, см',
  lengthTitle: 'Длина, см',
  otherTitle: 'Другие размеры',     // для значений, не похожих на «ШxД»
  hintText: 'Выберите ширину и длину',
  resetText: 'Сбросить размеры',
  doneText: 'Готово',               // кнопка внизу попапа (если Битрикс ещё
                                    // не прислал «Показать N товаров»)
  showCounts: true,                 // количество товаров рядом с длиной
  moveInputs: true,                 // позиционирование «Показать N товаров»
  popupWidth: 344,                  // ширина панели на десктопе, px
  mobileMedia: '(max-width: 767px)', // порог мобильной шторки
  quickTitle: 'Популярные размеры',
  quickSizes: ['160x200', '140x200', '180x200', '90x200'], // вверху попапа
  quickSizeCount: 4,                // сколько кнопок показать (макс.)
  skuEnabled: true                  // тот же попап на детальной (.bx_item_detail_size)
};
</script>
```

Акцентный цвет наследуется из переменной темы Аспро `--theme-base-color`. Переопределить можно в CSS:

```css
.sf-size-picker, .sf-popup { --sf-accent: #1f8449; }
```

## Как ведёт себя пикер

- Поле показывает текущий выбор: «Выберите размер» → «160×200» →
  «Выбрано размеров: 3». Под полем — чипсы выбранных размеров с крестиками
  и ссылка «Сбросить размеры».
- Вверху попапа — 3–4 популярных размера (`quickSizes`). Клик сразу
  включает или снимает пару Ш×Д, без выбора ширины и длины по отдельности.
  Если размера нет в текущем фильтре, кнопка не показывается;
  `quickSizes: []` скрывает блок.
- Ниже в попапе: клик по **ширине** делает её активной (контурная рамка), в
  колонке длин появляются количества товаров; клик по **длине**
  включает/выключает размер (заливка с галочкой ✓, уходит штатный ajax).
  Можно и наоборот: сначала длина — колонка ширин отфильтруется.
- Число на кнопке ширины — сколько длин выбрано с этой шириной.
- Недоступные комбинации (нет товаров или Битрикс пометил `disabled`)
  гаснут. Счётчики обновляются вслед за Битриксом.
- На **детальной** (SKU) выбирается один размер: клик переключает торговое
  предложение через штатный `change` селекта Аспро, попап закрывается.
  Чипсы и сброс нескольких размеров там не нужны.
- Закрытие: крестик, клик мимо панели, Esc, кнопка внизу. На мобильных —
  ещё и тап по тёмной подложке.
- После каждого клика Аспро перерисовывает фильтр целиком — попап при этом
  **переоткрывается сам**, выбранная ширина и прокрутка колонок
  сохраняются, так что можно выбрать несколько размеров подряд.
- Значения свойства, не распознанные как «ШxД» (например «круглый»),
  показываются кнопками в блоке «Другие размеры» внутри попапа; они
  участвуют в чипсах и сбросе наравне с остальными.

## Технические детали

- Распознаются форматы `80x190`, `80х190` (рус. «х»), `80×190`, `80*190`,
  дробные `82,5x190` (выводятся с запятой).
- **Анти-FOUC**: при загрузке скрипт сразу добавляет `<style>`, скрывающий
  исходный список чекбоксов до инициализации — сырой список не мелькает ни
  при первой загрузке, ни после ajax. Если пикер построить не удалось
  (ошибка, меньше двух значений «ШxД»), блоку возвращается штатный вид
  (класс `sf-native`, страховочный таймер 4 с).
- Повторная инициализация после ajax: `MutationObserver` на `document.body`
  + событие `BX.onCustomEvent('onAjaxSuccess')`, срабатывает синхронно до
  отрисовки кадра. Если набор значений не изменился (обычный случай),
  пикер **не пересоздаётся**: его живые DOM-узлы переносятся в новый блок
  и перепривязываются к новым чекбоксам (`rebind`) — обновляются только
  счётчики, доступность и текст «Показать N товаров», попап не мигает.
  Полная пересборка происходит лишь при изменении набора значений.
  Состояние (ширина, прокрутка, открытость попапа) хранится в JS по
  `data-property_id` и переживает перерисовку.
- `moveInputs: true`: перед `click()` чекбокс переносится в видимый
  элемент пикера **внутри формы фильтра** (поле, ряд чипсов или ссылка
  сброса — они не пересоздаются при перерисовке) — тогда `BX.pos()` в
  `smartFilter.click()` возвращает осмысленные координаты. В попап чекбокс
  не переносится: попап при открытом состоянии перекрыл бы всплывашку.
- Попап прикреплён к `.bx_filter_parameters_box` (не к `.bx_filter_block`),
  поэтому не конфликтует со сворачиванием группы фильтра в Аспро
  (`slideUp`/`slideDown` по клику на заголовок) и с ограничением высоты
  `limited_block`.
- Доступность: `role="dialog"`, `aria-modal`, `aria-pressed` на кнопках,
  `aria-expanded` на поле, закрытие по Esc, возврат фокуса на поле,
  тап-зоны ≥40px на мобильных, контраст текста ≥4.5:1.
- Если в блоке меньше двух значений «ШxД», фильтр остаётся как был.
